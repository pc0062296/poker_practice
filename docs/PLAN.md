# 撲克現金局練習程式：實作計畫（第二版）

目標：幫使用者準備澳門／台灣線下 9-max 無限注德州撲克現金局。
提供接近實戰的練習環境，為每個決策評分，並能復盤線下實際打過的手牌。

## 已確認的需求

- 平台：網頁 App（TypeScript + React + Vite），用 GitHub Pages 發布，手機可安裝成 PWA
- 盲注 0.5 / 1 BB，買入 200–250 BB（預設 200 BB，可設 100 / 200 / 250 或自訂）
- 主要 9-max，人數可調 2–9
- 翻前、翻後都要練，每個行動都要評分
- 評分兩把尺：「基準打法偏差」與「對這桌的 EV」
- 內建近似範圍表，也支援使用者匯入自己的範圍表
- 評分預設在一手結束後顯示
- 真實復盤：輸入線下打過的手牌，依序重播，顯示對手大概的範圍並為決策評分
- 不做 AI 教練講解

## 核心設計判斷

1. 進步速度取決於每分鐘遇到幾個有意義的決策，所以有三種訓練形式共用同一個引擎：
   牌桌模式、局面訓練、快練。
2. 線下桌獲利主要來自剝削，基準打法是沒有讀牌資訊時的底線，所以評分有兩把尺。
3. 評分要標示可信度：
   - 精確：跟注全下、河牌跟注或棄牌、河牌下注，可以列舉對手範圍直接算出
   - 估計：翻牌、轉牌上還有後續行動的決策，靠模擬估計，附誤差
4. 電腦是規則寫成的，會有不像真人的破綻。當「對這桌最賺」的打法和基準差很多時要提醒。
   對手類型隱藏時以基準尺為主。
5. 不做用完就丟的東西。電腦的策略介面從第一版就固定：
   對範圍裡的每一手牌輸出各動作的機率。出牌、範圍推算、評分共用同一個函式。
   策略函式只拿得到公開資訊，看不到任何人的底牌。

## 程式碼慣例

- 程式碼（變數、註解）使用英文 ASCII；介面中文字串集中在 `src/i18n/`
- 金額一律用整數單位，1 BB = 100 單位
- 規則引擎、評估器、範圍、電腦都是純邏輯模組，不依賴介面

## 資料夾結構

```
src/
  engine/   規則引擎（發牌、下注、邊池、抽水、牌局流程、牌桌）
  eval/     牌型評估器、1326 種組合、牌面強度表、聽牌判斷
  ranges/   169 種起手牌、範圍文字格式、內建翻前範圍表、局面分類、標準尺寸
  bots/     策略介面、基準策略（翻前查表、翻後規則）、範圍推算
  game/     單手牌的執行流程（把引擎、策略、範圍推算、評分串起來）
  grading/  評分（目前只有翻前）
  storage/  IndexedDB 手牌紀錄
  store/    介面狀態
  ui/       React 元件
  i18n/     介面文字（繁中）
```

### 階段 0：骨架與部署
- Vite + React + TypeScript + Vitest
- GitHub Actions：每次 push 跑型別檢查、測試、建置；main 分支自動發布到 GitHub Pages
- PWA：manifest 與離線快取

### 階段 1：規則引擎與牌型評估器
- 洗牌：`crypto.getRandomValues` + Fisher-Yates；測試可指定種子
- 牌型評估器：位元遮罩式 5–7 張評估器
  - 驗證：全部 2,598,960 種 5 張組合與 133,784,560 種 7 張組合的牌型分佈與已知數字一致
- 狀態機：座位、按鈕輪轉、盲注、straddle、最小加注、
  不足額 all-in 不重開加注權（多個不足額 all-in 累積達完整加注時會重開）、
  邊池、平分底池與零頭、未被跟注的下注退回、抽水（百分比加上限、沒看翻牌不抽）、補碼與重買
- 每手記錄底牌、公共牌與所有動作，可以原樣重播
- 可以指定底牌與公共牌開局（給局面訓練與復盤用）
- 策略只能拿到公開資訊（`PublicView`）

### 階段 2：範圍系統
- 169 種起手牌的資料結構與 13×13 排列
- 範圍文字格式：`AA,KK,AKs,A5s:0.5,TT+,ATs+,A5s-A2s,T9s-76s`，可解析也可輸出
- 內建 9-max 近似範圍（100 BB 與 200 BB）：
  開池、對付平跟、面對開池（依開池者與自己的位置分組）、面對 3bet、面對 4bet
- 翻前局面分類：從行動紀錄判斷目前屬於哪一種局面
- 標準加注尺寸規則

### 階段 3：牌桌介面、第一版電腦、翻前評分
- 桌面版與手機直式版面；四色牌；發牌與下注動畫
- 行動面板：棄牌、過牌／跟注、加注滑桿與快捷尺寸、鍵盤快捷鍵
- 使用者棄牌後，剩下的電腦瞬間打完並直接進下一手
- 設定：人數、買入深度、補碼方式、straddle、抽水、速度、金額顯示單位
- 電腦（基準策略）：翻前查範圍表；翻後依手牌對對手範圍的強度、
  在自己範圍中的排名、聽牌、底池賠率決定，並依下注尺寸控制詐唬比例
- 範圍推算：每個動作之後，用同一個策略函式更新每位玩家的範圍
- 翻前評分：比對使用者動作與範圍表頻率；可開啟該局面的範圍表對照
- 手牌存入 IndexedDB

### 階段 4：快練與工具箱
- 翻前快練：隨機局面連續作答，可選位置與情境，記錄各局面正確率
- 範圍檢視、編輯（13×13 塗色）、匯入匯出
- 勝率計算機：手牌對範圍、範圍對範圍
- 線下心算題：底池賠率、勝率估計、底池計算

### 階段 5：對手模型與範圍推算
- 兩種策略引擎：
  - 真人型：看絕對牌力加傾向參數，模擬線下常見玩家
  - 基準型：看手牌在自己範圍裡的相對強弱（階段 3 的版本繼續加強）
- 玩家類型：基準、TAG、LAG、緊弱、跟注站、鬆被動平跟型、瘋子
- 自訂對手：入池率、加注率、3bet%、翻後激進度、詐唬頻率，或「只打前 X% 的牌」
- 兩套範圍推算：「一般觀察者會怎麼想」與「依電腦實際策略」
- 牌桌預設、對手籌碼深淺不一、換桌友
- 校準：電腦互打，檢查各類型的統計符合設定

### 階段 6：翻後評分
- 精確類：列舉對手範圍直接算 EV
- 估計類：模擬到攤牌，各候選動作共用同一批隨機牌，附誤差
- 每個決策一張解說卡：各動作 EV、底池賠率、對範圍勝率、對手範圍組成、MDF、SPR
- 舊手牌回溯評分；在背景執行

### 階段 7：真實手牌復盤
- 手牌輸入：人數、位置、籌碼、盲注、自己的底牌、依序輸入每個動作與公共牌、攤牌看到的牌
- 可以為每位對手標記類型（不確定就用一般線下玩家）
- 依序重播：每個動作之後顯示每位對手的推算範圍（13×13 熱圖與成牌、聽牌、空氣比例）
- 對使用者的每個決策評分（基準尺；有標記對手類型時加上剝削尺）
- 復盤紀錄可儲存、匯出

### 階段 8：局面訓練與線下實戰模式
- 從指定局面開局；位置鎖定；自動跳過一定棄牌的手牌
- 隱藏底池數字並考底池大小；自己輸入下注金額；隱藏對手類型

### 階段 9：複盤、統計、弱點加強
- 回放、上帝視角、重打同一手牌
- 單場報告、漏洞分類、進步曲線、弱點加強出題
- 匯出與匯入備份

### 階段 10：單挑河牌與轉牌求解器
- 自己實作 CFR 求解器，先河牌再轉牌
- 翻牌求解計算量太大，維持選做

## 已知限制

- 內建範圍是依公開資訊編寫的近似值，不是 solver 的輸出
- 階段 10 之前，翻後的基準打法是規則寫成的，不是真正的均衡解
- 電腦像不像真人取決於對各類玩家的假設，所以參數開放調整
