# 撲克現金局練習程式：實作計畫

目標：模擬澳門／台灣線下 9-max 無限注德州撲克現金局，讓使用者練習翻前與翻後決策，並為每個行動評分。

> 注意：這是第一版計畫。修訂版（調整實作順序、評分可信度分級、局面訓練、線下實戰模式）
> 正在等使用者確認，確認後本文件會改寫。

## 使用者需求（已確認）

- 平台：網頁 App（TypeScript + React + Vite），之後可安裝成 PWA 在手機、平板離線使用
- 盲注 0.5 / 1 BB，買入 200–250 BB（預設 200 BB，可設 100 / 200 / 250 或自訂）
- 主要 9-max，人數可調 2–9
- 翻前、翻後都要練，並有行動評分
- 評分兩把尺：「GTO 偏差」與「對這桌的 EV」
- 預設範圍表由程式內建（近似值），也必須支援使用者匯入自己的範圍表
- 評分預設在一手結束後顯示，可開學習模式即時提示

## 核心設計判斷

1. 線下桌獲利主要來自剝削，GTO 是沒有讀牌資訊時的基準線。
2. 9-max 多人底池多，solver 不適用，主要評分改用「模擬 EV」：
   電腦對手的策略完全已知，因此可以用貝氏更新精確推算對手範圍，
   再對每個候選動作做大量模擬，算出每個動作的 EV。
   評分使用對手的「範圍」，不是真實底牌，因此不是結果論。
3. GTO solver 只作為單挑局面的參考解，放在後期。

## 程式碼慣例

- 程式碼（變數、註解）使用英文 ASCII；介面中文字串集中在 `src/i18n/`
- 金額一律用整數「單位」，1 BB = 100 單位，避免浮點誤差
- 規則引擎、評估器、AI 都是純邏輯模組，不依賴 UI，方便測試與之後搬到 Web Worker

## 資料夾結構

```
src/
  engine/   規則引擎（發牌、下注、邊池、抽水、牌局流程）
  eval/     牌型評估器、起手牌分類
  bots/     電腦對手（玩家類型、範圍估計、決策）
  ranges/   範圍表資料與編輯器（Phase 3）
  grading/  評分引擎（Phase 5）
  storage/  IndexedDB 手牌紀錄（Phase 6）
  store/    UI 狀態（zustand）
  ui/       React 元件
  i18n/     介面文字（繁中）
docs/       計畫與說明
```

### Phase 0：專案骨架
- Vite + React + TypeScript + Vitest
- 依上方結構建立資料夾

### Phase 1：規則引擎與牌型評估器
- 洗牌：`crypto.getRandomValues` + Fisher-Yates（測試用可指定種子）
- 牌型評估器：位元遮罩式 5–7 張評估器
  - 驗證：全部 2,598,960 種 5 張組合與 133,784,560 種 7 張組合的牌型分佈要與已知數字一致
- 狀態機：座位、按鈕輪轉、盲注、straddle、最小加注、不足額 all-in 不重開加注權
  （多個不足額 all-in 累積達完整加注時會重開）、邊池、平分底池與零頭、
  未被跟注的下注退回、抽水（百分比 + 上限、沒看翻牌不抽）、自動補碼／重買
- 每手產出結構化事件紀錄
- 完成標準：邊界案例測試全過；隨機模擬大量手數籌碼總量守恆

### Phase 2：牌桌介面與基本電腦
- 9 人橢圓牌桌，使用者固定在下方中間；四色牌可切換；下注與發牌動畫
- 行動面板：棄牌、過牌／跟注、加注滑桿與快捷尺寸、鍵盤快捷鍵
- 使用者棄牌後，剩下的電腦瞬間打完並直接進下一手
- 設定：人數、買入深度、電腦買入範圍、補碼方式、straddle、抽水、電腦速度、對手風格
- 基本電腦（v0）：翻前依手牌強度百分位與位置決定；翻後用蒙地卡羅勝率
  對估計範圍，加上底池賠率決策。Phase 4 會整個換掉

### Phase 3：翻前範圍系統、翻前評分、翻前快練
- 169 種起手牌 × 動作頻率；依「位置 × 情境 × 籌碼深度」分類
- 預設近似範圍（標示為近似值）；13×13 範圍編輯器；JSON 匯入匯出
- 評分：比對使用者動作與範圍頻率，混合策略的牌兩種動作都算對
- 快練模式：隨機翻前局面連續作答

### Phase 4：對手模型、翻後策略、範圍追蹤
- 玩家類型：GTO 基準、TAG、LAG、緊弱、跟注站、鬆被動平跟型、瘋子
- 牌桌預設：澳門常見桌、台灣常見桌、全基準桌、逐座自訂
- 翻後策略以 MDF、詐唬比例、範圍優勢等原則定基準頻率，再依類型參數調整
- 因策略已知，範圍可用貝氏更新精確推算
- 完成標準：電腦互打 10 萬手，各類型統計落在目標附近

### Phase 5：翻後評分引擎
- 對每個候選動作：從推算範圍抽對手手牌 → 模擬到攤牌，數千次取平均（Web Worker）
- 所有候選動作共用同一批隨機牌以降低誤差
- 輸出各動作 EV 與 EV 損失、等級（最佳／良好／不精確／錯誤／大錯）
- 解說：底池賠率、對範圍勝率、範圍組成、MDF、SPR、阻斷牌
- 限制：模擬中使用者後續行動由基準策略代打

### Phase 6：復盤、統計、錯題本
- 手牌回放與決策標註；單場報告（每百手 EV 損失、all-in EV 調整、漏洞分類）
- 個人統計與建議區間對照；錯題用間隔重複再出題

### Phase 7：單挑翻後 GTO 參考解
- 接開源 postflop-solver（Rust → WASM，AGPL 授權：自用可，公開散佈需開源）

### Phase 8：讀人訓練
- 隱藏電腦類型讓使用者判斷；玩家筆記
